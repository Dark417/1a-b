# 12 · Agent / AI-Engineer Skills

Deep, self-contained **explainer files** — one per skill — for the 32
knowledge areas an **AI engineer** is hired for. This section operationalizes the
ranked list derived in section 11: each numbered skill from
[`../11.agent-ai-engineer/agent-ai-engineer.skill.md`](../11.agent-ai-engineer/agent-ai-engineer.skill.md)
gets a rich `NN.<slug>.md` here, named per the canonical slugs in
[`../11.agent-ai-engineer/03.ranked-skills.md`](../11.agent-ai-engineer/03.ranked-skills.md).

Every file follows the same shape so you can learn a skill *from that file
alone*: **What it is · Why employers want it · Mental model · The landscape ·
Worked example · How to learn it · Interview signals · Cross-links · References.**
The number is the **canonical rank** (most → least demanded); it is stable and
seeds the filenames here.

> **Tiers.** 01–10 **Core** (table stakes, absence is disqualifying) · 11–22
> **Important** (strong demand, expected for most applied roles) · 23–32
> **Differentiating** (raises you above the bar or gates a specialist role).

## How to use this section

- **Learners:** start with Tier 1 (01–10) — your non-negotiable base. Build one
  project that exercises #01–#10 together (a RAG + agent app with evals on the
  cloud), then pick a Tier-3 specialty to stand out.
- **Interviewers / hiring:** require Tier 1, treat Tier 2 as a strong plus, and
  pick Tier 3 items only when the role genuinely needs them.
- **Navigation:** every file cross-links to the others and to the numbered
  curriculum sections (`../02.dl/`, `../05.transformers/`, `../07.frameworks/…`,
  `../09.huggingface/`, `../10.gpu/`, …).
