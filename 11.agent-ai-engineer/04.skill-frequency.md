## What's moving (trend narrative)

- **Fastest risers (↑↑):** prompt engineering & LLM APIs (#04), agents (#06),
  evaluation (#07), safety/guardrails (#19), LLM observability (#22), multimodal
  (#25), and MCP/agent protocols (#32). These cluster around the **agentic +
  production-reliability** shift of 2025–2026.
- **Stable core (→):** Python/SWE (#01), ML/DL foundations (#02), PyTorch (#08),
  cloud (#10), data engineering (#14) — the durable base that every cohort needs.
- **Softening (↓):** classic ML / pure data-science (#31) as a *standalone*
  AI-engineer requirement — still valuable judgment, but less often the headline
  ask versus the LLM stack.

## Reading the numbers honestly

- Shares **don't sum to 100%** — each role asks for many skills, so this is
  multi-label frequency, not a partition.
- The estimate is **ordinal**: trust "#04 outranks #16," not "80% vs 45%" to two
  significant figures. See [`01.research-method.md`](01.research-method.md) §6 for
  the full list of biases (sample not random, title-soup merging, recency skew).
