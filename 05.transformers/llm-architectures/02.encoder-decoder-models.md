# 02 · Encoder-decoder models — T5, BART, mT5, UL2

> **Intuition.** Some tasks are inherently *input → output*: translate this,
> summarize that, answer this question. An **encoder-decoder** (seq2seq) reads
> the whole input bidirectionally (the encoder), then *generates* the output
> autoregressively (the decoder), with **cross-attention** letting each generated
> token look back at the full encoded input. This cleanly separates
> "understanding the source" from "producing the target."

---

## 1. The architecture in words

Two stacks (Vaswani et al. 2017):
- **Encoder:** bidirectional self-attention over the input → contextual memory.
- **Decoder:** *causal* self-attention over the output-so-far **+ cross-attention**
  into the encoder memory **+** FFN. Trained with teacher forcing to predict the
  next target token.

Cross-attention is the bridge: decoder queries, encoder keys/values.

$$\text{CrossAttn}(Q_{\text{dec}}, K_{\text{enc}}, V_{\text{enc}}) = \text{softmax}\!\Big(\tfrac{Q_{\text{dec}} K_{\text{enc}}^\top}{\sqrt{d_k}}\Big) V_{\text{enc}}$$

## 2. T5 — Text-to-Text Transfer Transformer (Google, 2019)

**Key idea: cast *every* NLP task as text → text.** Translation, classification,
summarization, even regression — all become "input string → output string,"
prefixed by a task tag (`"translate English to German: ..."`,
`"cola sentence: ..."` → `"acceptable"`). One model, one loss, one decoding loop.

**Pretraining: span corruption.** Mask contiguous *spans* (avg length 3); replace
each with a unique sentinel token `<X>`, `<Y>`; the decoder must emit the dropped
spans. More efficient than single-token masking and aligned with generation.

**Architecture details.** Encoder-decoder; **relative position bias** (a learned
scalar added to attention logits per relative-distance bucket, shared across
layers) instead of absolute embeddings; RMSNorm-like LayerNorm without bias;
sizes from 60M (small) to **11B** (T5-XXL). Trained on the **C4** corpus
(Colossal Clean Crawled Corpus). The T5 paper is also a giant *ablation study* of
objectives, architectures, and data.

**Variants:**
- **mT5** — multilingual T5, 101 languages, mC4 corpus. Same recipe, no
  task prefixes baked in.
- **Flan-T5** — T5 further **instruction-tuned** on ~1,800 tasks phrased as
  instructions (the Flan collection). Dramatically better zero/few-shot and
  chain-of-thought; the go-to small instruction model. (See
  `11.training-and-alignment.md` for instruction tuning.)
- **T0, ByT5 (byte-level), LongT5** (efficient long-input attention) — further
  branches.

## 3. BART — Bidirectional and Auto-Regressive Transformer (Meta, 2019)

A **denoising autoencoder** for seq2seq. Corrupt the input with an arbitrary
noising function, then train the full encoder-decoder to **reconstruct the
original** text. Noising functions tried: token masking, **token deletion**,
**text infilling** (replace a span with a single `[MASK]` — the model must guess
*how many* tokens), sentence permutation, document rotation. Text infilling +
sentence shuffling worked best.

Think of BART as "BERT's bidirectional encoder + GPT's autoregressive decoder,
trained to denoise." It excels at **summarization and generation** (CNN/DailyMail,
XSum) where T5 also shines; mBART extends it multilingually for translation.

---

## 4. UL2 — Unifying Language Learning (Google, 2022)

Argues the *pretraining objective* should not be a binary choice. UL2 trains one
model on a **Mixture-of-Denoisers (MoD)**:

- **R-denoising** — regular T5-style span corruption (short spans, low rate).
- **S-denoising** — sequential / prefix-LM (predict the continuation; GPT-like).
- **X-denoising** — extreme span corruption (long spans and/or high mask rate).

Each example is tagged with a **mode token** (`[R]`, `[S]`, `[X]`) so the model
learns to switch behaviors; at inference you pick the mode that fits the task.
UL2 (20B) can act as both an encoder-decoder *and* a prefix-LM. **U-PaLM**
applies UL2's objective to continue-train PaLM.

---

## 5. Why decoder-only mostly displaced seq2seq

For *open-ended generation and chat*, a single decoder-only stack (`03.gpt-line.md`)
is simpler, scales cleanly, and a long context window subsumes the
"encode-then-decode" split (just put the source in the prompt). Encoder-decoders
remain strong where input and output are clearly distinct and you want an
explicit bidirectional read of the source: **translation, summarization, and
small efficient task models (Flan-T5)**.

## 6. Component links

- Position: T5's relative bias is a cousin of **ALiBi** (`02.alibi.py`) and
  **RoPE** (`01.rope.py`) — all encode *relative* distance.
- Norm/FFN: modern re-implementations of T5/UL2 swap in **RMSNorm**
  (`06.rmsnorm.py`) and **GeGLU/SwiGLU** FFNs (`05.swiglu.py`).
- Decoding uses the same **KV cache** (`08.kv_cache.py`) on the decoder side;
  the encoder is computed once.
