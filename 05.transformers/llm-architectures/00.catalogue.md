# 00 · The LLM Architecture Catalogue (classic → SOTA → variants)

A single master table of the language models that matter, from the 2018
encoder/decoder split to the 2025 sparse-MoE + reasoning frontier. Use it as an
index: each *family* has a deep-dive explainer (`01`–`10`) and most *mechanisms*
have a runnable PyTorch component in this folder (`01.rope.py` … `15.quantization.py`).

> **How to read this.** Params are given as a *range* when a family ships
> multiple sizes; for MoE models we give **total / active** (active = params used
> per token). Context = max trained/served context window (many extend further
> via RoPE scaling — see `01.rope.py` and `11.training-and-alignment.md`).
> Items that are **not publicly confirmed** (e.g. GPT-4 / Gemini internals) are
> flagged **(inferred)**. Citations live in `12.references.md`.

---

## Legend

| Token | Meaning |
|---|---|
| **enc** | encoder-only (bidirectional, masked-LM pretraining) — understanding/embedding |
| **dec** | decoder-only (causal, autoregressive) — generation; the dominant LLM shape |
| **enc-dec** | encoder-decoder (seq2seq) — translation, summarization, T5-style text-to-text |
| **MoE** | Mixture-of-Experts: sparse FFN, only top-k experts fire per token (`07.moe.py`) |
| **SSM** | State-Space Model (Mamba) — linear-time sequence model, no attention (`12.ssm_mamba.py`) |
| **hybrid** | mixes attention with SSM/linear-attention/MoE layers (Jamba, RWKV) |
| **GQA/MQA** | Grouped-/Multi-Query Attention — KV-head sharing (`03.gqa_mqa.py`) |
| **MLA** | Multi-head Latent Attention — low-rank KV compression (`04.mla.py`) |
| **RoPE / ALiBi** | rotary / linear-bias position encoding (`01.rope.py`, `02.alibi.py`) |
| **SwiGLU** | gated FFN activation (`05.swiglu.py`); **RMSNorm** = `06.rmsnorm.py` |
| **MTP** | multi-token prediction objective (`14.mtp.py`) |
| **(inferred)** | architecture/size not officially disclosed; community estimate |

**Gemma**/**Qwen**/**Command** = source-available custom licenses (some
restrictions) · **Proprietary** = API-only, weights closed.

   `03.gpt-line.md` — the encoder/decoder/seq2seq split and why decoder-only won.
2. **The open backbone:** `04.llama-line.md` — the four ingredients (RMSNorm,
   RoPE, SwiGLU, GQA) every modern model now uses.
3. **Sparsity & efficiency:** `05.mistral-mixtral.md`, `06.qwen-deepseek.md` —
   sliding windows, MoE, MLA, MTP, RL reasoning.
4. **Labs:** `07.google-models.md`, `08.other-open-models.md`.
5. **Beyond text & beyond attention:** `09.multimodal.md`, `10.non-transformer.md`.
6. **Training:** `11.training-and-alignment.md`. **Citations:** `12.references.md`.
