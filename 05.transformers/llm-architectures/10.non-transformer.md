# 10 · Beyond attention — Mamba/SSMs, RWKV, Jamba, RetNet

> **Intuition.** Attention is $O(n^2)$ in sequence length and its KV cache grows
> linearly — painful for very long sequences. The alternatives ask: *can we get a
> model that trains in parallel like a transformer but runs in **constant memory
> per step** like an RNN?* State-space models (Mamba), linear-attention RNNs
> (RWKV), and retention (RetNet) all answer yes, with different math. Jamba shows
> you can **mix** them with attention for the best of both.

---

## 1. State-Space Models → Mamba — `12.ssm_mamba.py`

A linear **SSM** maps input $x_t$ to output $y_t$ through a hidden state $h_t$:

$$h_t = \bar A\,h_{t-1} + \bar B\,x_t,\qquad y_t = C\,h_t$$

With *fixed* $\bar A, \bar B$ this is **linear time-invariant**: it can be written
as a **global convolution** and trained in parallel over the whole sequence
(FFT/scan), yet **run as a recurrence** at inference with $O(1)$ state per step.
Earlier SSMs (S4) used clever HiPPO initialization to capture long-range
structure.

**Mamba's key idea — selectivity (S6).** Make $\bar B, C$ (and the timestep
$\Delta$) **functions of the input** $x_t$. Now the model can *choose* what to
remember or forget based on content — closing the quality gap with attention on
language. The price: input-dependent parameters break the convolution trick, so
Mamba uses a **hardware-aware parallel scan** (work-efficient associative scan in
SRAM) to stay fast.

**Mamba-2 (SSD).** Reframes selective SSMs via **State-Space Duality**: the SSM
is equivalent to a structured (semiseparable) matrix multiply, so it can reuse
**matmul/attention-style hardware** and be trained much faster, with a cleaner
multi-head formulation.

**Tradeoff:** linear-time, constant-memory decoding, great on very long
sequences; but pure SSMs can lag attention on tasks needing precise **in-context
recall/copying** — which motivates hybrids (§3).

---

## 2. RWKV — a linear-attention RNN/transformer hybrid — `13.rwkv.py`

RWKV ("RwaKuv") is trained **like a transformer** (parallelizable) but runs
**like an RNN** (constant memory, $O(1)$ per token, *unbounded* context). It
replaces softmax attention with a **WKV** operator: a weighted sum over the past
with a **per-channel exponential time-decay** $w$ plus a "bonus" $u$ for the
current token — a linear attention that admits a recurrent form:

$$\text{wkv}_t = \frac{\sum_{i<t} e^{-(t-1-i)w + k_i} v_i + e^{u+k_t} v_t}{\sum_{i<t} e^{-(t-1-i)w + k_i} + e^{u+k_t}}$$

Channel-mixing and time-mixing blocks replace FFN and attention. Versions 4→6
(Eagle/Finch) add data-dependent decay and matrix-valued states, narrowing the
gap to transformers. Apache-2.0, 0.1B–14B.

---

## 3. Jamba — a hybrid (AI21, 2024)

Don't choose — **interleave**. Jamba stacks **blocks** that mix **Mamba layers**
(cheap, long-range, constant-memory) with periodic **attention layers** (precise
recall) **and MoE** FFNs (capacity). The Mamba majority keeps the KV cache tiny
so it serves a **256k context** (and more) on modest memory; the occasional
attention layer restores the copying/recall ability pure SSMs lack;
MoE (`07.moe.py`) adds capacity at low active compute (**52B total / 12B
active**). Apache-2.0. Jamba is the practical argument that *hybrid* beats either
pure approach today.

---

## 4. RetNet — Retentive Networks (Microsoft, 2023)

Proposes **retention** as an attention replacement with a "**impossible
triangle**" claim — one mechanism with **three equivalent forms**:
- **Parallel** form for efficient *training* (like attention).
- **Recurrent** form for $O(1)$ *inference* (like an RNN).
- **Chunkwise** form for efficient *long-sequence* processing (chunks parallel
  inside, recurrent across).

Retention multiplies a causal decay mask $\gamma^{n-m}$ into a QKᵀ-style score
(no softmax), giving a linear recurrence. Conceptually close to RWKV/linear
attention with an explicit decay.

---

## 5. How they compare

| | Transformer | Mamba (SSM) | RWKV | RetNet | Jamba (hybrid) |
|---|---|---|---|---|---|
| Train | parallel | parallel scan | parallel | parallel | parallel |
| Decode mem/step | grows (KV cache) | $O(1)$ state | $O(1)$ state | $O(1)$ state | small (mostly SSM) |
| Long-context cost | $O(n^2)$ | $O(n)$ | $O(n)$ | $O(n)$ | near-$O(n)$ |
| Exact recall/copy | strong | weaker | weaker | weaker | strong (attn layers) |

## 6. Strengths / limits

These models shine when **context is huge and memory is the bottleneck**
(streaming, documents, audio). Their weakness is precise associative recall and
the smaller ecosystem/tooling vs transformers. The pragmatic winner so far is
**hybrid** (Jamba): SSM efficiency + a little attention for recall + MoE for
capacity.
