# 09 · Multimodal models — CLIP, Flamingo, LLaVA, Qwen-VL, GPT-4V, Whisper

> **Intuition.** To make an LLM *see* or *hear*, you need to turn pixels/audio
> into tokens the transformer can attend to. Three patterns dominate: **align**
> two modalities in a shared embedding space (CLIP), **inject** visual features
> into a frozen LLM via cross-attention (Flamingo) or a projector (LLaVA), or
> build a model **natively multimodal** from the start (GPT-4o, Gemini). Whisper
> shows the same transformer toolkit handles speech.

---

## 1. CLIP — Contrastive Language–Image Pretraining (OpenAI, 2021)

Two encoders — an **image encoder** (ViT or ResNet) and a **text encoder**
(Transformer) — trained on 400M (image, caption) pairs to **agree**. For a batch
of N pairs, maximize cosine similarity of the N matched pairs and minimize it for
the N²−N mismatches (a symmetric InfoNCE / contrastive loss):

$$\mathcal{L} = \tfrac12\big(\text{CE}(\text{logits}_{i\to t}) + \text{CE}(\text{logits}_{t\to i})\big),\quad \text{logits}=\tfrac{I V^\top}{\tau}$$

The payoff: a **shared embedding space** enabling **zero-shot classification**
(embed class names as text, pick the nearest) and image–text retrieval. CLIP's
image encoder became the **standard "eyes"** bolted onto downstream VLMs (LLaVA,
many others). MIT.

---

## 2. Flamingo — few-shot VLM via gated cross-attention (DeepMind, 2022)

Connects a **frozen vision encoder** and a **frozen LLM** with two trainable
bridges:
- **Perceiver Resampler** — turns a variable number of image features into a
  **fixed small set** of visual tokens (cross-attention to learned latents).
- **Gated cross-attention** layers interleaved into the frozen LLM, with a
  **tanh gate initialized at 0** so training starts as the untouched LLM and
  *gradually* learns to attend to images (stable).

Result: a model that does **few-shot, interleaved image-and-text** prompting.
Proprietary; OpenFlamingo reproduces it.

---

## 3. LLaVA — the simple, dominant open recipe (2023)

**CLIP image encoder → a small MLP projector → a frozen/then-tuned LLM (Vicuna/
LLaMA).** The projector maps CLIP visual features into the LLM's token-embedding
space; image "tokens" are simply prepended to the text tokens. Two-stage train:
(1) align the projector on image–caption pairs, (2) **visual instruction tuning**
on GPT-4-generated multimodal conversations. Astonishingly effective for its
simplicity → became the default open VLM template (LLaVA-1.5/1.6, many forks).
Apache-2.0.

---

## 4. Qwen-VL / Qwen2-VL (Alibaba, 2023–24)

A production open VLM line. Qwen2-VL adds **naive dynamic resolution** (process
images at native, variable resolution → variable visual tokens) and **M-RoPE**
(multimodal rotary positions encoding time/height/width — extends `01.rope.py` to
2-D/3-D). Strong at **OCR, document understanding, grounding, and video**. 2B–72B,
Qwen/Apache licenses. (Family overview in `06.qwen-deepseek.md`.)

---

## 5. GPT-4V and GPT-4o (OpenAI) — notes

- **GPT-4V (2023):** vision added to GPT-4; strong general visual reasoning.
  **Architecture undisclosed (inferred** to be a vision encoder feeding the
  GPT-4 backbone).
- **GPT-4o (2024):** **natively** "omni" — one model processing **text, audio,
  and image** in and out, enabling real-time voice with low latency. Internals
  undisclosed **(inferred)**. The shift from *bolt-on adapter* to *native
  multimodal tokens* mirrors Gemini.

---

## 6. Whisper — robust speech recognition (OpenAI, 2022)

A plain **encoder-decoder Transformer** for ASR/translation. Audio → log-Mel
spectrogram → conv stem → Transformer encoder; a decoder generates text
conditioned via cross-attention, using **special tokens** to select the task
(transcribe vs translate), language, and timestamps. The trick is **scale +
weak supervision**: **680k hours** of diverse, loosely-labeled web audio → strong
**zero-shot** robustness across accents, noise, and languages without
dataset-specific fine-tuning. MIT. Sizes 39M–1.5B.

---

## 7. The three integration patterns (summary)

| Pattern | Example | How vision meets the LLM |
|---|---|---|
| **Align** (dual encoder) | CLIP | shared contrastive embedding space |
| **Inject** (cross-attn) | Flamingo | gated cross-attention into frozen LLM |
| **Project** (prefix tokens) | LLaVA, Qwen-VL | encoder → projector → tokens prepended |
| **Native** | GPT-4o, Gemini | one model, interleaved multimodal tokens |
